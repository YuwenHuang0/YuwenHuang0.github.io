01 / Quick start

快速复现

A. 精确定理证书

仅需 Python；使用有理数精确运算。

$ python code/dqi_reliability_sensitivity_audit.py

预期：237 个径向、79 个非对称恒等式通过。

B. 数值实验环境

在网站根目录安装唯一第三方依赖。

$ python -m pip install -r code/requirements.txt

如已有 NumPy，可直接执行后续命令。

C. 72×45 BP-OSD 探针

固定 seed 260902、25 次迭代和两组列重。

$ python code/reproduce_bp_osd_confirm.py

默认新建 reproduced CSV，不覆盖原始数据。

D. 小码同成本审计

重跑 5 个有限码长实例及配对估计。

$ python code/dqi_bp_osd_matched_cost_audit.py

会重生成同名结果目录中的聚合文件。
