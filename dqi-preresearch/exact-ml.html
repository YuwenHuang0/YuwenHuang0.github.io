01 / Metrics and controls

指标与同成本对照

Z = Σₑ π(e) 1{D(He) = e} ℰ = Σ{e,e′}: accepted, dH=1 √(π(e)π(e′)) J = 1/2 + ℰ/(mZ), R = Z(J − 1/2) = ℰ/m

Z · 接受概率

也是 BSC 下经典帧成功概率。对照组与 DQI 感知组逐综合征选择相同重量，故 Z 完全相同。

J · 条件得分

在接受条件下衡量相邻接受错误对的贡献；下表增益记为 ΔJ。

R · 尝试加权超额

保留后选择成本，是更审慎的译码设计目标；其增益记为 ΔR。

受控变量：常规 BP-OSD 使用 BP 后验度量破并列；DQI 感知 BP-OSD 使用固定 0 < 1 字典序。二者的 OSD 列表和最小重量主指标相同，在线 BP 边更新与 OSD 试验数相同。

04 / Reproduction

重跑同成本审计

需要 Python 与 NumPy。在网站根目录运行：

$ python -m pip install -r code/requirements.txt
$ python code/dqi_bp_osd_matched_cost_audit.py

脚本将重新生成 code/dqi_bp_osd_matched_cost_results/ 下的 CSV、JSON 和 Markdown 报告。运行时间会随机器变化，不属于算法指标。
