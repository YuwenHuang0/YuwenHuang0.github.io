BP 门限预研数据说明

此实验与 72 比特 BP-OSD、9/12 比特精确最大似然实验分别进行。
关联纠错码长度 m=600、2400、9600；校验方程数 n=m/2。
每个错误码位参与 3 个校验，每个校验涉及 6 个码位。
随机种子 2026；BP 最多迭代 60 次。每个错误比例分别进行 300、200、100 次试验。
每个长度使用一张随机正则校验图，固定错误重量抽样；图中曲线是保存的聚合恢复率。
当前保存文件 prelim_bp.npz，不含原始逐次日志。

作图：进入本目录，安装 requirements.txt，运行 python plot_threshold.py。
重跑仿真：先复制本目录再运行 python simulate_threshold.py；运行可能较长，会覆盖该副本中的聚合数组。
右图 J_ref=1/2+sqrt(rho(1-rho)) 是 DQI 原文条件下的门限换算，不是本仿真的实际 DQI 输出，也不是通用严格界。
