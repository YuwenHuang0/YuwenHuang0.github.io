01 / Ordered ML rule

显式最优 ML 并列规则

对独立比特先验 0 < pᵢ < 1/2 与正坐标奖励 γᵢ，定义：

λᵢ = log((1 − pᵢ) / pᵢ), rᵢ = √((1 − pᵢ) / pᵢ) L(e) = Σᵢ λᵢeᵢ, Gγ(e) = Σᵢ:eᵢ=1 γᵢrᵢ

每个综合征内依次执行

  1. 主规则：最小化 L(e)，即精确 ML；
  2. 次规则：在 ML 纤维内最大化 Gγ(e)；
  3. 末规则：按固定、次数相容的乘法单项式序取最小代表。

所得像集向下闭，并在所有确定性 ML 截面中全局最大化接受边加权和。手稿进一步给出“纤维内势损失 + 缺失向下边界”的精确两项缺陷，刻画全部最优解。

02 / Reliability–sensitivity

最优接受边加权和 = 理想项 + 可靠性方向导数

令 ZML(p) 为经典 ML 成功概率。对特定方向 vᵢ = γᵢ√pᵢ(1−pᵢ)3/2，定理给出：

maxT: ML ℰγ,T = Dᵥ⁺ ZML(p) + bγ(p) ZML(p) bγ(p) = Σᵢ γᵢ √(pᵢ(1−pᵢ))

方向导数非正，因此理想乘积态项是上界，其精确损失由经典 ML 可靠性的方向灵敏度给出。在相同比特、均匀奖励情形，还得到有限码长微分式与面积恒等式。

03 / Coefficientwise optimum

径向振幅下的逐系数最优性

对任意二元线性码，按重量优先、再以固定字典序选择每个陪集的最小重量代表，可使每个汉明层的接受边数同时达到上界 Nₖ = k nₖ。因此同一规范截面同时优化所有非负径向振幅剖面。

maxD: ML PD(q) = W′ML(q) PT(q) = W′ML(q) − Δ↓(T; q)

这里 WML(q) = Σₖ nₖqᵏ；Δ↓ 精确记录缺失的向下接受边。

237 个径向及 79 个非对称恒等式

证书使用 Python 标准库 Fraction 进行有理数精确运算，在穷举的小二元码上独立检查径向导数恒等式及非对称方向导数扩展，不以浮点近似代替证明。
