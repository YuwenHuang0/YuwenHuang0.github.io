03 / Evidence boundary

原始 CSV 不含逐次日志

必须保留的限制：原始文件只有两行聚合数据及均值字段，没有逐矩阵、逐试验的错误向量、综合征、译码输出、运行时间或失败原因日志。

因此不能从该 CSV 重建每次试验，也不能据此进行逐次配对检验或重新计算置信区间。复跑会生成新的聚合结果；这里不声称存在未保存的逐次证据。

04 / Reproduction

复现两行聚合结果

需要 Python 与 NumPy。在网站根目录执行以下命令；包装脚本显式固定列重列表 [5, 9]、错误率输入 [0.1]（经程序取整为 7 errors）及全部其余参数。

$ python -m pip install -r code/requirements.txt
$ python code/reproduce_bp_osd_confirm.py

默认写入 code/results/bp_osd_dqi_probe_confirm.reproduced.csv，避免覆盖原始 CSV。也可指定输出：

$ python code/reproduce_bp_osd_confirm.py --output code/results/my_confirm.csv
